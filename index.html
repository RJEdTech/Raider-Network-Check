RJ Network Check

Find out exactly what got blocked on a student laptop, and why. Everything runs on this computer. The log file is never uploaded anywhere.

1 · Record

  1. Open a new Edge tab and go to edge://net-export (Edge won't let a page link there, so paste it into the address bar.)
  2. Pick Strip private information, then click Start Logging to Disk and save the file (Downloads is fine).
  3. In another tab, do the thing that's broken: load the site, open the assignment, click the button.
  4. Go back to the net-export tab and click Stop Logging.

IT fallback: Windows packet capture (needs admin)

Use this for non-browser traffic, or when edge://net-export is blocked. Run it in an elevated PowerShell on the laptop. You'll only see DNS lookups, server names, and resets, not full URLs, because the traffic is HTTPS.

pktmon start --capture --pkt-size 0 -f C:\Temp\capture.etl
# reproduce the problem, then:
pktmon stop
pktmon etl2pcap C:\Temp\capture.etl -o C:\Temp\capture.pcapng

Open capture.pcapng in Wireshark on a staff machine. Useful filters: dns, tls.handshake.extensions_server_name, tcp.flags.reset==1.
